# Rock Paper Scissors Game

A responsive Rock Paper Scissors game built with HTML, CSS, and JavaScript. Play against the computer, which picks its move randomly, and track the score as you play.

**Live Demo:** https://vikas-rock-paper-scissors-game.vercel.app/

## Features

- Choose Rock, Paper, or Scissors with a single click
- Computer picks its move randomly each round
- Shows the result of every round
- Keeps score for both the player and the computer
- Responsive layout

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Play

1. Click Rock, Paper, or Scissors.
2. The computer picks its move.
3. The winner of the round is shown and the score updates.

## Run Locally

1. Clone the repository: `git clone https://github.com/VikasThakur-tach/Rock-Paper-Scissors--Game.git`
2. Open the `Rock-Paper-Scissors` folder.
3. Open `index.html` in your browser.
